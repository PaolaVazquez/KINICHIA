# KINICHIA

KINICHIA es una solución de seguridad digital que utiliza inteligencia artificial para analizar comunicaciones y detectar posibles señales de fraude, estafa o riesgo.

## Objetivo

El objetivo de KINICHIA es ayudar a las personas a identificar posibles amenazas presentes en mensajes y correos electrónicos antes de que realicen alguna acción que pueda poner en riesgo su información.

La aplicación analiza el contenido y contexto de las comunicaciones, identifica señales sospechosas, muestra la evidencia encontrada y proporciona recomendaciones para que el usuario pueda tomar una decisión informada.

## Herramientas utilizadas

### Frontend
- **React Native** — Desarrollo de la aplicación móvil.
- **Expo** — Entorno de desarrollo y ejecución de la aplicación.
- **TypeScript** — Tipado y desarrollo del proyecto.
- **Expo Router** — Navegación entre pantallas.
- **NativeWind** — Estilos y diseño de la interfaz.

### Backend
- **NestJS** — Desarrollo de la API y lógica del servidor.
- **Prisma** — ORM para la gestión de la base de datos.
- **PostgreSQL** — Sistema de gestión de base de datos.

### Inteligencia Artificial
- **Google Gemini** — Motor de inteligencia artificial utilizado para analizar el contenido de las comunicaciones y detectar señales de riesgo.

### Herramientas de desarrollo
- **Git y GitHub** — Control de versiones y gestión del repositorio.
- **TablePlus** — Administración y consulta de la base de datos.

## Resultado obtenido

Se desarrolló un prototipo funcional de KINICHIA capaz de analizar comunicaciones y presentar los resultados de manera clara para el usuario.

El sistema permite:

- Analizar conversaciones y correos electrónicos.
- Detectar diferentes señales relacionadas con posibles fraudes.
- Clasificar el nivel de riesgo.
- Mostrar una puntuación de riesgo.
- Presentar evidencia encontrada directamente del contenido analizado.
- Proporcionar recomendaciones de seguridad.
- Consultar análisis de conversaciones previamente procesadas.
- Utilizar inteligencia artificial mediante Google Gemini para realizar el análisis.

El resultado es una solución funcional que demuestra cómo la inteligencia artificial puede utilizarse como una **capa de seguridad para las comunicaciones digitales**, ayudando a los usuarios a reconocer posibles amenazas y tomar decisiones más seguras.
